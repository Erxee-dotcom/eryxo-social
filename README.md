# ERYXO Social

ERYXO Social is a modern social platform with an integrated Work Hub.

## Project Structure

- `client/` — Frontend application
- `server/` — Backend application
- `shared/` — Shared types and utilities

## Core Technologies

- React
- TypeScript
- Express
- Firebase
- Firestore
- Cloudinary

## Deployment

The application is prepared for Node.js deployment using Render.

## Important

Existing backend functionality, Firebase integration, Cloudinary uploads, authentication, routes and application features should be preserved.
